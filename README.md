## File Guide

This repository contains scripts for the following paper:

[Curko et al., Remembered Event Features Shape Default Mode Network Engagement during Emotional Memory Recall](https://doi.org/10.1523/ENEURO.0146-26.2026)

| File | Description |
|---|---|
| `Reframe-detail-main-paper.Rmd` | univariate activity analyses in the DMN, amygdala, and hippocampus |
| `Reframe-detail-wholebrain-paper.Rmd` | Whole-brain parcel analyses of univariate activity |
| `Reframe-detail-RSA-networks-paper.Rmd` | Main representational similarity analysis (RSA) of DMN subnetworks |
| `Reframe-detail-RSA-wholebrain-paper.Rmd` | Whole-brain representational similarity analysis (RSA) |
| `Reframe-detail-success-ratings-paper.Rmd` | Analyses of success ratings and their relationships with behavioral and neural data |
| `Reframe-detail-addl-analyses-paper.Rmd` | Additional analyses characterizing the paradigm, including inter-rater reliability and emotional valence categorization |
